# Fast Food Bulevard — site demo

Propunere de site pentru Fast Food Bulevard (Bd. Victoriei nr. 8, Tecuci). Demo realizat de Manotek.

- Next.js (App Router) + TypeScript + Tailwind, export static pe GitHub Pages.
- **Tot conținutul se editează în `content/site.ts`** (meniu, prețuri, ofertă, livrare, program).
- Tot ce e marcat `[de completat]` trebuie confirmat de proprietar.
- La lansare: `site.demo.enabled = false` (scoate banda demo și permite indexarea).

```bash
npm install
npm run dev          # local
npm run build        # export static în out/
```
